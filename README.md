# CrushWall 心动墙

免登录的校园表白墙 / 匿名社区，单页应用 + PHP + SQLite 极简架构，任意支持 PHP 的虚拟主机即可部署。

## 功能

- **免登录**：首次访问自动分配设备 ID（cookie + localStorage 双写），换设备不丢身份
- **自定义头像**：相册上传 + 方形裁剪器（拖动/缩放/双指捏合）+ 压缩到 256px，全站统一显示，可一键恢复默认
- **表白墙 / 论坛**：发帖（文字 + 多图 + 匿名 + 分类）、点赞、评论、收藏、删除、搜索、无限滚动
- **话题房**：6 个真实匿名房间，聊天式气泡流 + 底部输入框，房间内强制匿名
- **好友系统**：帖子页点"加"发申请 → 通知中心同意/拒绝 → 好友列表管理，全程免登录
- **主题装扮**：6 套主题色 + 4 种气泡样式，CSS 变量真实生效，本地持久化
- **心动电台**：内置音乐播放器，页面底部悬浮入口 + 全局迷你播放条 + 全屏播放器，开局默认随机播放并自动开播，支持列表/单曲/随机三模式、切歌预热加速、播放进度本地记忆
- **全白屏律动动感效果**：全屏播放器背景为「全白屏」柔光斑（紫/粉/蓝），由 Web Audio `AnalyserNode` 实时提取音频能量驱动；中央黑胶唱片圆盘随低音能量**来回收缩脉动**（圆形元素随音乐伸缩），外侧彩色律动光环扩散收缩，歌名下 26 根频谱柱实时跳动；迷你播放条圆盘同步脉动 + 三根律动柱由真实音频驱动
- **音效模式切换**：全屏播放器右上角音效按钮弹出面板，可切换「原声 / 3D 环绕（StereoPanner 左右来回环绕 + 回声空间感）/ 重低音（lowshelf 低频增强）/ 人声增强（peaking 中频突出）/ 自定义（低音、高音、空间感三个滑杆）」五种模式，选择持久化到本地
- **后台音乐管理**：超管后台「音乐管理」tab 可直接上传音频（mp3/wav/flac/aac/m4a/ogg，最大 30MB）、**拖拽排序**（按住行左侧「≡」手柄上下拖动，实时换位，也可用 ▲▼ 按钮，写入 `.order.json`）、重命名、**每首歌可点击「试听」直接播放预览**；「上传音乐」入口亦保留
- **IP 记录与封禁**：发帖/评论自动记录来源 IP（`posts.ip`），后台「帖子管理」列表直接显示 IP 并可一键封禁；被封禁 IP 发帖/评论返回 403，后台「IP 管理」可解封
- **用户封禁**：后台「帖子管理」「评论管理」可对作者一键封禁用户，「用户管理」列表可封禁/解封（`users.banned`），被封禁用户发帖/评论返回 403；超管不可被封禁
- **好友私信**：好友列表点「私信」进入私密聊天，消息仅好友双方可见（`messages` 表按好友对隔离），聊天记录缓存到各人本地（localStorage 离线可看），进入聊天页自动标记已读，自己发的消息显示「已读/未读」回执，好友列表显示未读红点，聊天显示对方头像；未读消息并入好友 tab 徽标，全局每 30 秒轮询未读数，有新私信自动 toast 提醒
- **好友搜索添加**：好友页顶部搜索框按昵称或设备号找人（`user.search`），结果直接「加好友」发申请，已是好友可一键私信，待处理申请显示状态；「我的」页设备号点击即复制，发给朋友就能加自己
- **访客记录**：「我的」页显示最近 20 位看过你帖子的人（昵称 + 头像 + 时间，`visits` 表按 访问者/被访问者 去重，同一访客重复访问只刷新时间），自己看自己不记录，访客隐私保护（不暴露设备号）
- **防刷屏**：发帖/评论/私信三层防护——基础间隔限制（发帖 10s/评论 5s/私信 2s/点赞 2s）、60 秒内累计发言 ≥ 5 次拒绝（`rate_logs` 计数）、与本人最近 5 条发言内容相同（去空白后）拒绝（防重复刷屏）；不同用户互不影响
- **DDoS 自动防护**：同一 IP 在 60 秒内请求数 ≥ 600（10 req/s）自动永久封禁（阈值兼容校园 NAT 共用出口），封禁名单可在后台管理
- **DDoS 自动防护**：同一 IP 在 60 秒内请求数 ≥ 300 自动永久封禁（`request_limits` 计数 + 写入 `banned_ips`，reason 标注「疑似 DDoS」），后台手动封禁 IP 即为永久生效（等同封 99 年）
- **律动波浪播放器**：全屏播放器黑胶圆盘随播放**快速旋转**（5s/圈）且为多彩 conic 渐变（每首歌色相不同、旋转时颜色流转）；频谱区改为方框内**一条多彩波浪线**随音频上下起伏（渐变描边 + 面积填充 + 顶部亮线，颜色随时间流动）；迷你条三根律动柱改为青/粉/紫三色
- **PWA**：可添加到手机主屏幕，离线可用，秒开加载（manifest + Service Worker）
- **图片画廊**：帖子多图全屏预览，左右滑动切换
- **超管后台**：真实验证登录，帖子/评论/用户管理，统计概览
- **安全**：参数化 SQL、输出转义防 XSS、上传白名单 + 图片二次校验、接口频率限制、管理员 HMAC 签名 token、**后台密码 bcrypt 哈希存储（`password_verify` 校验）+ 登录失败锁定（连续 5 次错误按 IP 锁定 15 分钟）+ DDoS 高频请求自动永久封禁**

## 开源说明

- 默认后台账号：`admin`（密码已随机化，无默认口令）——部署前请务必通过环境变量 `CW_ADMIN_PASSWORD` / `CW_ADMIN_SECRET` 设置后台密码与 token 签名密钥，否则实例以随机凭据运行且不可恢复，详见下方部署说明
- 此开源版本已移除生产环境的百度推送 Token、管理员密钥、真实域名等敏感信息
- 数据库（`cw-api/data/`）与上传文件（`cw-api/uploads/`）默认 gitignore 不入库

## 部署

### 1. 修改配置

编辑 `cw-api/config.php`：

```php
    define('ADMIN_PASSWORD', getenv('CW_ADMIN_PASSWORD') ?: bin2hex(random_bytes(16))); // 必须设置环境变量 CW_ADMIN_PASSWORD
    define('ADMIN_SECRET', getenv('CW_ADMIN_SECRET') ?: bin2hex(random_bytes(32))); // 必须设置环境变量 CW_ADMIN_SECRET
```

### 2. 上传到服务器

把整个 `crushwall/` 目录上传到虚拟主机的 web 根目录（如 `htdocs/`、`www/`）。
要求 PHP 7.4+，启用 `pdo_sqlite` 扩展（默认开启）。

数据库文件与上传目录会在首次访问时自动创建，请确保 `cw-api/` 目录可写。

### 3. 访问

浏览器打开 `https://你的域名/crushwall/index.html` 即可使用。

## 技术说明

- 身份：`device_id` 即身份，服务端首次访问自动建号，匿名帖对他人隐藏 device_id 与真实昵称，展示稳定生成的"诗意昵称"
- 好友：`friend_requests` 表记录申请，`friends` 表存双向关联（user_a < user_b）
- 管理鉴权：`ADMIN_SECRET` + HMAC-SHA256 无状态 token，12 小时过期
- 频率限制：发帖 10s/次、评论 5s/次、点赞 2s/次（SQLite rate_limits 表）
- 音乐：`config.php` 的 `MUSIC_DIR` 指向音乐目录（默认 `cw-api/music/`），`MUSIC_URL_BASE` 为相对访问路径（默认 `music/`）；支持 mp3/flac/wav/ogg/m4a/aac，按目录内 `.order.json` 中的文件名数组排序；nginx 上用 `location /music/ { alias ...; }` 提供文件访问
- 音乐上传：`upload.php` 的 `type=music` 需携带管理员 token，校验音频 MIME 与大小（`MUSIC_MAX_SIZE`，默认 30MB），保存到 `MUSIC_DIR`，重名自动追加随机后缀
- 音乐管理：`admin.music_order` 校验文件名真实存在后写 `.order.json`（顺序契约）；`admin.music_rename` 重命名文件（同目录 `rename` 失败时 `copy`+`unlink` 兜底）并同步 `.order.json`
- IP 封禁：`banned_ips` 表（ip 为主键），`clientIp()` 取真实 IP（优先 `CF-Connecting-IP`/`X-Forwarded-For`），发帖/评论前 `isIpBanned()` 校验返回 403；`posts` 表含 `ip` 列（建表 + ALTER 兼容老库）
- 头像/昵称与帖子同步：帖子列表、评论、话题房气泡均通过 `JOIN users` 实时读取当前头像与昵称（非匿名帖；匿名帖对他人隐藏头像/昵称、自己可见），修改头像/昵称后前端 `reloadFeeds()` 刷新即可全局同步

## 兼容性说明

- 服务器 SQLite 版本较老（如 CentOS 7 自带 3.7.x）时**不支持 UPSERT（`ON CONFLICT`）语法**，本项目已用「先 UPDATE 后 INSERT」的兼容写法，勿改回 UPSERT
- 需要在 nginx 等反向代理层为 `music/` 配 `Range` 支持（默认开启）以保证播放器拖动进度

## 高并发优化说明

本项目 SQLite 连接已做以下并发保护（`cw-api/db.php`），修改时请勿移除：

- `PRAGMA journal_mode = WAL`：读写不互斥，读请求不阻塞写事务
- `PRAGMA busy_timeout = 10000`：遇写锁等待最多 10 秒，避免并发瞬间直接抛 "database is locked" 500
- `PRAGMA synchronous = NORMAL`：WAL 模式下崩溃安全与写入速度的平衡，缩短锁持有时间
- 高频写降频：`autoDdosGuard` 计数按进程静态缓存节流（同 IP 每 2 秒至多写一次，`INSERT OR IGNORE` + `UPDATE` 合并避免并发首插竞态）；`getOrCreateUser` 的 `last_active` 每 5 分钟才更新一次；`request_limits` 过期清理仅在窗口轮换时执行
- 聚合读收敛：`visitor.info` 等接口的多条 `COUNT(*)` 合并为单条 SQL，减少 PHP↔SQLite 往返

## 每日盲盒说明

「我的 → 每日盲盒」每日 1 次免费抽取（`users.last_box` 原子占位防并发双抽，24h 冷却服务端校验），掉落头像框/气泡皮肤/称号/积分四类物品（`config.php` 的 `$BLIND_BOX_POOL`，概率权重只在服务端）：

- **物品池**：`blindbox_items` 表（启动幂等 seed），掉落记录在 `blindbox_records`，图鉴按用户聚合
- **API**：`box.status`（图鉴+冷却+当前装备）、`box.draw`（原子抢锁抽奖，冷却返回 429）、`box.equip`（手动切换已拥有的装扮，未拥有返回 403）
- **奖励接入**：头像框（`users.avatar_frame`，af- 前缀样式）、气泡皮肤（`users.bubble_skin`，话题房气泡 `bubble-skin-*` 样式）、称号（`users.title`，昵称旁 `title-badge` 徽章）；帖子/评论/话题房/排行/主页均实时展示
- **前端**：`index.html` 拆盒动画、稀有度配色、收藏图鉴墙、24h 倒计时；主题装扮页「盲盒装扮」区可切换已拥有物品
- 防作弊：前端不参与概率计算，冷却与掉落校验全在服务端，`box.equip` 每次校验 `blindbox_records` 拥有记录

## 深夜模式说明

「顶部月亮按钮」切换三态：自动（22:00-06:00 生效）/ 开启 / 关闭，状态存 `localStorage.cw_night`，每分钟检查时段自动切换无需刷新：

- `data-night="on"` 属性块定义在全部主题变量之后，覆盖 `--bg/--card/--text/--grad` 等核心变量，**任何主题下深夜都统一为暗色**（不依赖 night 主题）
- 星空背景：`html[data-night="on"] body` 叠加 9 颗 radial-gradient 星星（背景层天然在内容之下，不遮挡交互）
- 进入深夜每日 toast 提醒一次（`cw_night_toast` 按日期去重）
- 适配修正：播放器全屏背景 `#fff`→`var(--bg)`、光斑 `multiply`→`screen`（暗色下彩色光斑更亮）、迷你音乐条 `rgba(255,255,255,.92)`→`var(--card)`

## CP 缘分值说明

「用户主页」查看他人时显示双方缘分值卡片，匹配页列表内嵌缘分徽章，全部由服务端根据真实互动数据实时计算（`index.php` 的 `cpScore`）：

- **计分公式**：双向心动 +45 / 单向心动 +10；好友 +10、好友天数每 5 天 +1（上限 15）；私信往来 3+log 增长（上限 10）；点赞/评论/礼物双向互动每项 +2（上限 20）；总分 min(100)
- **六档等级**：灵魂伴侣 95+ / 天生一对 80+ / 相见恨晚 60+ / 互有好感 40+ / 有缘相识 20+ / 缘未到 <20；查看自己返回 100 灵魂伴侣
- **API**：`cp.value`（to_user_id 传对方，返回 score/level_name/slogan/detail 明细）；`crush.matches` 列表内嵌 `cp` 字段免二次请求
- **明细维度**：双向心动、好友天数、私信条数、互动次数，前端缘分卡片分点展示
- **数据源**：crushes / friends / messages / likes+posts / comments+posts / gift_logs 六张真实互动表，无独立刷分入口

## 谁心动了你

「我的 → 谁心动了你」展示所有对你心动的人（含单向与双向），补上心动闭环：被心动的人立刻知道，回心动即匹配成功：

- **后端**：`crush.received` API 查询 crushes 表 to_user=me 列表，附加 mutual（是否双向）/is_friend/cp 缘分值；**不返回 device_id 保护隐私**（进主页用 user_id 即可）
- **通知**：`crush.send` 单向心动时给对方发「心动了你」通知（type=crush），复用现有未读红点 + 30s 轮询 + toast；点击通知跳转「谁心动了你」页
- **前端**：列表项显示昵称/头像/时间/状态徽章（单恋中💗/互有好感💘/已是好友💑）+ 缘分徽章；单向时「回心动」按钮一键双向（匹配成功即双方收到 crush_match 通知），双向未好友时「去匹配」直达匹配页，均提供「主页」入口
- **闭环**：被心动 → 查看 → 回心动 → 匹配成功 → 私信，全部免登录完成

## 缘分海报说明

用户主页缘分卡片底部「生成缘分海报」一键生成可保存/分享的 600x900 竖版海报图（canvas 绘制，纯前端无后端改动，复用 `cp.value` 数据）：

- **视觉**：背景渐变按缘分等级配色（灵魂伴侣金红/天生一对粉紫…），双方头像圆框（无头像自动画渐变首字母）、中间 💘、大缘分数字投影、等级徽章、slogan、明细行、底部网站落款
- **交互**：全屏遮罩预览，`保存海报` 走 canvas.toBlob 触发下载，`关闭` 返回；提示长按可保存到相册（手机分享给好友/发朋友圈）
- **实现要点**：头像用 `loadAvatar`（Image + crossOrigin anonymous，失败降级首字母）；`roundRect` 手写兼容老浏览器；昵称/文案 `truncate` 截断防溢出

## 心动理由说明

心动时附一句想对 TA 说的话（表白墙灵魂，可选 ≤50 字），被心动方在「谁心动了你」里直接看到：

- **存储**：`crushes` 表新增 `reason` 列（db.php 建表 + 幂等迁移 PRAGMA 检查补列，旧数据默认空串）
- **后端**：`crush.send` 接受可选 `reason`（trim + mb_strlen 限 50 字，mb_substr 截断）；通知内容带上理由「心动了你：xxx」；`crush.received` 返回对方理由、`crush.matches` 返回 TA 的理由（c2.reason）、`crush.status` 返回我写的理由
- **前端**：所有心动入口（用户主页 ❤ 心动、帖子浮动操作栏、谁心动了你「回心动」）统一弹「心动一下」输入框（textarea 实时字数 0/50）；「谁心动了你」列表显示「💬 TA 说：xxx」、匹配页显示同样样式
- **兼容**：不带 reason 的旧调用完全兼容（默认空串）

## 积分抽盲盒说明

免费次数用完后可花积分立即再抽，把「签到/发帖赚积分 → 抽盲盒 → 掉装扮」串成完整经济循环：

- **定价**：`BOX_PRICE = 60` 积分/次（config.php，介于小卖部商品 50-200 之间）
- **后端**：`box.draw` 新增 `paid=1` 参数——付费模式用原子 UPDATE `score = score - 60 WHERE score >= 60` 扣分（rowCount=0 返回 402 积分不足，并发不会透支），**不占用免费冷却**（不更新 last_box，不影响明日免费次数，可连抽）；免费模式保持原原子占位逻辑完全不变；`box.status` 新增返回 `price`
- **前端**：盲盒页免费礼盒下常驻「⚡ 花 60 积分再抽一发」按钮（积分不足显示灰色「再攒 X 分可抽」）；点击 confirm 确认防误触；冷却倒计时下方同样可付费再抽
- **防作弊**：价格与扣分全在服务端，前端只传 `paid=1` 标志；免费与付费两条路径互不干扰
